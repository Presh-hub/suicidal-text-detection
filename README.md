# Suicidal and Non-Suicidal Text Classification

An academic Natural Language Processing project exploring machine-learning
and deep-learning approaches for classifying social-media text into
suicidal and non-suicidal categories.

## Project Overview

The project investigates different NLP approaches for binary text
classification.

The experiments include:

- TF-IDF
- Logistic Regression
- Word2Vec
- Random Forest
- LSTM
- Transformer/Attention
- BERT

## Dataset

The experiments use a labelled text dataset containing suicidal and
non-suicidal social-media posts.

The dataset is not stored directly in this repository.
